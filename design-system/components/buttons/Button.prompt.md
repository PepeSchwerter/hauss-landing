Primary call-to-action button used across HAUSS marketing surfaces; sharp 4px corners, 2px border, yellow fill by default.

```jsx
<Button variant="primary" size="md">Get a quote</Button>
<Button variant="dark" icon="→">See our work</Button>
```

Variants: `primary` (yellow, main CTA), `dark` (ink fill, secondary CTA on light bg), `ghost` (outline, on light bg), `inverse` (white, for dark sections). Sizes: `sm`, `md`, `lg`. Pass `disabled` to dim and block clicks.
